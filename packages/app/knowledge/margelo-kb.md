# Margelo knowledge base

Source-of-truth notes about Margelo, compiled from margelo.com, github.com/margelo,
and mrousavy.com (verified 2026-07-02), plus a few team-provided facts (people and
culture) supplied internally. Each `##` section is written to stand on its own so
it can be retrieved as a single chunk. Web facts are limited to what the primary
sources state; anything they did not cover is either team-provided (clearly the
people/culture section) or omitted rather than guessed.

## What Margelo is

Margelo is a high-end app development agency focused on React Native, iOS, and
Android. Its GitHub organization describes it as a "High-end App Development
Agency focused on React Native." Its positioning on margelo.com is "App
Development, done right" and "We will help you ship better apps, faster." The
company both builds apps for clients and maintains widely used open-source
React Native libraries.

## Services Margelo offers

Margelo offers: full app design and development (from idea to the App Store);
performance optimization (startup time, animations, scroll and gesture
smoothness); custom native module development (UIs, animations, gestures, native
platform features); camera integration (filters, AR, pro-photography features);
on-device AI (LLMs, Apple Intelligence, LiteRT, PyTorch, ONNX); and consulting
and bug fixing.

## Clients Margelo has worked with

Margelo works with high-profile clients. Named clients include Shopify, Rainbow,
Discord, Red Bull, WalletConnect, Expensify, VSCO, Picnic, Status, Exodus,
Coinbase, and NativeScript, among 30+ others listed on margelo.com.

## Notable client work

Specific projects Margelo highlights: Stori (face filter design and
development), VSCO (camera app development), Discord (migration to React
Native's New Architecture), and MyGroove (a high-performance audio and video
engine).

## Margelo's open-source footprint

Margelo is a major open-source contributor in the React Native ecosystem. The
company reports 284 commits to React Native core and maintains projects with
over 22 million downloads. Many of its libraries are performance-focused native
modules written in C/C++ with JSI or built on Nitro Modules.

## Nitro Modules

Nitro (Nitro Modules) is a framework, created by Margelo, for building fast
native modules for React Native. Several of Margelo's newer libraries are built
on top of Nitro, including react-native-nitro-sqlite (a fast SQLite library,
~554 GitHub stars) and react-native-nitro-fetch (a super-fast network fetching
library with prefetching support, ~904 stars).

## react-native-vision-camera

react-native-vision-camera is Margelo's camera library for React Native,
described by its author as "the best Camera library for React Native." It
supports advanced camera features such as filters, AR, and pro-photography
capabilities.

## react-native-mmkv

react-native-mmkv is Margelo's key/value storage library for React Native,
described as "the fastest key/value storage for React Native," built because
other storage solutions were too slow.

## Other notable Margelo libraries

Margelo maintains many high-performance React Native libraries, including:
react-native-graph (beautiful, high-performance graphs and charts built with
Skia, ~2.6k stars); react-native-quick-crypto (a fast implementation of Node's
crypto module in C/C++ JSI, ~1k stars); react-native-bignumber (the fastest Big
Number library, ~378 stars); react-native-worklets-core (run JS "Worklets" on
separate threads, ~787 stars); react-native-runtimes (run heavy components and
logic in isolated Hermes runtimes, ~535 stars); react-native-fast-tflite (a fast
TensorFlow Lite library); and react-native-blurhash (a native Blurhash
placeholder view).

## Founder: Marc Rousavy

Marc Rousavy is the founder and CEO of Margelo. He is a prominent React Native
open-source author whose personal site (mrousavy.com) reports roughly 21K
Twitter followers and 42K GitHub stars. He is the original author of several of
Margelo's best-known libraries, including Nitro, react-native-vision-camera, and
react-native-mmkv, and has contributed to react-native-reanimated,
react-native-skia, and React Native core. On a personal note, Marc likes fast
cars.
